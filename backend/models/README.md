# SupplyPrescript V2 model artifacts

Copy the eight trained V2 artifacts generated by the ML notebook into this folder:

- final_xgboost.pkl
- final_lightgbm.pkl
- final_catboost.pkl
- final_features.pkl
- final_categorical_features.pkl
- final_category_levels.pkl
- final_threshold.pkl
- final_ensemble_config.pkl

The backend reads this folder by default. You can override it with the
`SUPPLYPRESCRIPT_MODEL_DIR` environment variable.
